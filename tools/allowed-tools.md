# Allowed Tools

Use this file to define what AI may safely inspect or operate.

## Safe By Default

- Read files in this repo
- Summarize notes
- Draft plans and memos
- Suggest memory updates

## Ask First

- Sending emails or messages
- Publishing content
- Editing important business records
- Running commands that change files
- Accessing private accounts

## Never Do Without Explicit Approval

- Delete files
- Share private data externally
- Make purchases
- Contact customers
- Change pricing
