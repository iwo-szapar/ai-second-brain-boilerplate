08 / The one prompt

This builds
the whole thing.

Brief
You are helping me build my first AI Second Brain. This folder is empty — you will build everything from scratch. The goal is not a knowledge base. It is to stop re-explaining myself to AI, and build a semi-autonomous system that co-drives my operations.
Context
Iwo Szapar · Builder · Second Brain Factory / ISG · Goal: automate 90% of non-strategy work · Constraints: time, energy · Links: iwoszapar.com, linkedin.com/in/iwoszapar
Rules
Run phases in order. No files until I confirm the snapshot. Public info only, cite sources, never invent. Keep it small. Don't contact, publish, or send anything.
Phase 1
Research me. Folder is empty; research my site + LinkedIn via Anysite MCP. Output: verified / inferred / still unknown.
Phase 2
Play it back. Summarize me in one paragraph, quote two of my own phrases, then stop: "Did I get this right?"
Phase 3
Operating snapshot. Role, goal, constraints, projects, recurring work. Ask up to 3 questions. Confirmation gate before any file.
Phase 4
Scaffold the architecture. Create CLAUDE.md, README, memory/ (profile, goals, projects, decisions, examples), inbox/, skills/, tools/allowed-tools.md.
Phase 5
Build one skill. Use /skill-creator for the highest-leverage workflow: context, steps, output, quality gate, write-back.
Phase 6
Build one agent. A specialist with its own job, context, tools, and boundaries.
Phase 7
Connect one tool. Wire a real connection — Gmail, Calendar, or Stripe. Respect the allowed-tools boundary.
Phase 8
Use it. Run the skill on my real context. Jobs to be done. Make the value obvious.
Phase 9
Explain + write back. Explain the brain in plain English. Save new decisions, patterns, and open questions to remember.
