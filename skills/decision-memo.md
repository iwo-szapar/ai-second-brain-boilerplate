# Decision Memo Skill

Use this when I need to make a meaningful decision.

## Context To Load

- `CLAUDE.md`
- `memory/goals.md`
- `memory/projects.md`
- `memory/decisions.md`
- relevant notes from `inbox/`

## Steps

1. State the decision in one sentence.
2. Clarify the current goal and constraint.
3. List the realistic options.
4. Compare options by upside, downside, cost, reversibility, and learning value.
5. Recommend one option.
6. Define the next action.
7. Draft the memory write-back for `memory/decisions.md`.

## Output Format

# Decision

# Context

# Options

# Recommendation

# Next Action

# Memory Write-Back
