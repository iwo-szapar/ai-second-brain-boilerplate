# Daily Priorities Skill

Use this when I ask what to focus on today or this week.

## Context To Load

- `CLAUDE.md`
- `memory/profile.md`
- `memory/goals.md`
- `memory/projects.md`
- `memory/decisions.md`
- `memory/examples.md`
- relevant files from `inbox/`

## Steps

1. Identify the current business goal.
2. Identify the highest-leverage constraint.
3. List urgent open loops.
4. Rank possible actions by revenue impact, learning value, and time cost.
5. Return only the top 3 priorities.
6. Explain why each priority matters now.
7. Suggest what should be saved back to memory.
