# Opening Second Brain Answer

Use this as the opening "wow" moment in a live session.

The point is to show the difference between generic AI and AI with context before explaining the system underneath.

## Prompt

```text
Given everything you know about my current business, what should I focus on this week?

Use my goals, current projects, open loops, and recent decisions.
Return:
- top 3 priorities
- why now
- what not to do
- what should be remembered
```

## Example Stage-Safe Answer

```md
# What My Second Brain Says I Should Focus On This Week

## 1. Make the live session a proof artifact, not just a talk

Why now:
The session is the nearest high-leverage moment to show the difference between generic AI and AI with context. The goal is not to explain every technical layer. The goal is to make people feel: "I can build my first version this week."

Next action:
Build the session around one transformation:
blank AI chat -> context folder -> reusable workflow -> memory write-back.

## 2. Turn the boilerplate into a real follow-up asset

Why now:
If the session lands, people will ask, "How do I start?" The boilerplate gives them a concrete next step. A resource page makes the session useful after the call ends.

Next action:
Create a simple resource page where attendees can request the AI Second Brain Boilerplate.

## 3. Keep the demo simple enough that non-technical founders copy it

Why now:
If I show too much too early, people will think this is only for technical operators. The first version should feel like a small folder that helps AI remember how to work with you.

Next action:
Avoid MCP, agents, hooks, databases, and automation until the core idea lands.

# What Not To Do

Do not turn this into a tour of every AI tool.

Do not expose private business context.

Do not make the GitHub repo feel like the product.

The product is the pattern:
context, memory, workflow, write-back.

# What Should Be Remembered

The best opening is:
show the specific answer first, then reveal why it was possible.

A normal AI session gives you an answer.
A Second Brain makes the next answer better.
```

## Narration

Point out why this answer is specific:

- It knows timing.
- It knows active work.
- It knows what not to do.
- It suggests what to remember.

Say:

```text
This is not magic. It is context, memory, workflows, and write-back.
```

Transition:

```text
Now I am going to rebuild the pattern from scratch using a safe demo, so you can copy it.
```

## 30-Second Stage Script

```text
Before I explain what an AI Second Brain is, let me show you the difference.

This answer is not better because I wrote a clever prompt.
It is better because the AI had access to my goals, current projects, open loops, and recent decisions.

Now I will rebuild the same pattern from scratch with a safe fictional example.
```
